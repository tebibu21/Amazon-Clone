Amazon Clone 🛒
A fully functional e-commerce web application inspired by Amazon, built for educational purposes. This project focuses on implementing core e-commerce features like product listings, user authentication, a shopping cart, and payment processing.

🚀 Features
User Authentication: Secure Sign-up and Login using Firebase Auth or JWT.
Product Management: Browse products by categories with a responsive search bar.
Shopping Cart: Add, remove, and update quantities of items in real-time.
Payment Integration: Secure checkout flow powered by the Stripe API.
Order History: View previous orders and status updates.
Responsive Design: Optimized for desktop, tablet, and mobile viewing.

🛠️ Tech Stack
Frontend:
React.js (Functional Components, Hooks)
Redux or Context API (State Management)
CSS / Styled Components (UI Design)
Backend & Database:
Firebase (Firestore Database & Cloud Functions) or Node.js/Express
Stripe API (Payment Processing)

🧠 What I Learned
Global State Management: Handling complex data flows across multiple components.
Asynchronous Logic: Processing real-time payments and database writes.
Security: Implementing protected routes and handling sensitive user data.
